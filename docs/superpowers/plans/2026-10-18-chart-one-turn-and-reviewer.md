# Chart in one turn, with a reviewer and live dashboard: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/rig:chart N` runs gap pass, architect, QA and an Opus review in one turn and stops at one human gate; generators are Sonnet, the evaluator Opus, versions configurable; the dashboard shows agent models and live spend.

**Architecture:** Mostly skill and agent text plus three small script changes (`chartcheck.ts` rule, `modelstate.ts` + `sdlc.ts` journey field, `journey.ts` step flags) and the mod (`hooks/dashboard.tsx`). No new agent, no new hook event, no model call in a hook.

**Tech Stack:** TypeScript run by node (`node:test` spec files beside the scripts), Claude Code mod API (`claude-code/testing` in `hooks/dashboard.test.ts`).

**Spec:** `docs/superpowers/specs/2026-10-18-chart-one-turn-and-reviewer-design.md`

## Global Constraints

- Scripts at most 500 lines, skills and guides at most 60, mod files at most 300; the harness total stays under its cap (`scripts/size.spec.ts`).
- Core scripts name no language or tool (`neutrality.spec.ts`).
- No hook calls a model. `/rig:approve` stays human-only. The reviewer never edits and never blocks.
- No file under `agents/`, `skills/` or `templates/` contains a literal `claude-<family>-<n>` model id; aliases `sonnet` and `opus` only.
- Per `CLAUDE.md`: at most 4 subagent launches for this change, Sonnet implementers, one review of `git diff main...HEAD` at the end, `npm test` run once per task group and its output quoted.
- Fix the harness, not its output: `shop_app` is regenerated by re-running rig there, never hand-edited.
- Work on a branch `chart-reviewer` off `main`; commits end with the attribution line from the session.

## Review Focus

- A PRD whose gap pass finds nothing: the chart must skip the question step, not ask an empty `AskUserQuestion`.
- The reviewer returns `verdict: pass` with no findings: no fix round runs and `chart-review.md` still gets written.
- `model.json` absent or malformed: `status --journey --json` returns `agents: []`, never throws.
- `$.session.usage()` throws or returns no cost on a tick: the band keeps its last numbers and the timer keeps running.
- A second `session.start` (reload) must not leave two timers running.
