# Product brief

## Context and intent

Shopping Cart API: a lightweight REST service for one in-memory cart. A user adds an item (name, price, quantity), views one item by its generated id, and lists all items. Success is scenario S1 of sprint 0 working end to end over HTTP.

## Non-goals

- Do not add user authentication or multi-user carts.
- Do not add updating or deleting items.
- Do not add checkout, payments, taxes or discounts.
- Do not store the cart outside process memory.

## Architecture

See .rig/product/architecture.md. Decisions: .rig/product/adr/0001-item-id-format.md, .rig/product/adr/0002-error-response-format.md.

## Constraints

- Python 3.12 via uv, FastAPI, uvicorn, pytest.
- Local only: `make run`; no deployment, monitoring or rollback.
- Item: `id` string generated by the server and unique; `name` non-empty string; `price` number >= 0; `quantity` integer >= 1.
- Errors are `{"detail": "<message>"}`; a rejected POST is 400, an unknown id is 404.
- The PRD defines no NFR.

## Interfaces

- POST /items: docs/contracts/add-item.yaml
- GET /items/{id}: docs/contracts/get-item.yaml
- GET /items: docs/contracts/list-items.yaml
