# J3 build sprint 1 (every intent started with /rig-start, built, verified, PR'd and merged)
Each intent is a change under .rig/changes/<slug>/ and a merge on main. Cite file:line or command output.

- J3.1 [block] For every intent there is a merged change whose tests exist in tests/ and pass (run pytest -q).
- J3.2 [block] Every AC of the intents built is covered by a test whose name or docstring cites the AC id or its behaviour, and the test asserts the AC's exact values (for example 14 days, 3 loans, the exact error message in AC-5.2).
- J3.3 [block] No test is a tautology: none asserts only that code runs, or compares a value with itself, or mocks the function under test.
- J3.4 [block] The loan limit (3) and the loan period (14 days) are each defined in exactly one place in src/library; grep the literals and show the one definition.
- J3.5 [block] Storage writes are atomic (a temp file then rename) and no operation writes the data file when it raises an error.
- J3.6 [block] No file outside src/library, tests, pyproject.toml, docs and .rig was added or changed by the changes.
- J3.7 [block] Lending rules (the limit, the period, the overdue check) live in one module apart from the storage code; the storage code only loads and saves.
- J3.8 [warn] Commit history per intent is readable: one merge per intent, messages say what changed.
- J3.9 [warn] Nothing from the non-goals was built (fines, renewals, reports, a command line, a member registry).
- J3.10 [block] Two processes borrowing at the same moment lose no loan and never exceed the loan limit: run 20 concurrent borrow calls against one data file (a short Python script with multiprocessing) and show the loan count before and after.
- J3.11 [block] No behaviour in a change's spec.md drops a "never", a limit or a number from the requirements.md row it cites: run node .rig/bin/sdlc.ts approve <slug> --check for each change and quote any WARNING weakened line.
